# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](http://semver.org/spec/v2.0.0.html).

## 0.8.0
- Added `Copy Inspection Results (Compact)` to the Code Issues context menu.
- Grouped results by directory and file, combining identical messages and their line ranges to reduce copied output.
- Kept copying based on the already displayed inspection results, without rerunning inspection or navigating to issues.

## 0.7.10
- Migrated the Rider frontend startup activity from Java to Kotlin.
